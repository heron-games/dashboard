# Dashboard Client

Simple and minimalist React web application with Bootstrap styling.

## Requirements

- Node.js (v18 or higher)
- npm

## Installation

```bash
npm install
```

## Development

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173/`

## Build

Create a production build:

```bash
npm run build
```

## Preview Production Build

Preview the production build locally:

```bash
npm run preview
```

## Technologies

- React 19
- Vite 7
- Bootstrap 5
